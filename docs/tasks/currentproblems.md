## Выявленные уязвимости (security audit)

### [SEC-001] PATH: подмена xgamma / xrandr / systemd-detect-virt
- **Приоритет:** high
- **Vuln ref:** 1.1
- **Вердикт:** partially (условия: каталог с поддельным бинарём стоит в PATH раньше системного, или переменная PATH подменена до запуска приложения тем же пользователем/окружением)
- **Файлы:** `src/gamma_core.py`, `src/environment_checks.py`
- **Описание:** Исполняется первый найденный `xgamma` по `shutil.which`; вспомогательные утилиты вызываются по неполным именам и тоже резолвятся через PATH.
- **Рекомендации по исправлению:** опционально ограничить доверенными префиксами путей или фиксированными абсолютными путями для поддерживаемых ОС; задокументировать риск.
- **Артефакт:** `tests/security/test_sec_001.py`
